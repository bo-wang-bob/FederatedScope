# Federated Studio 前端

2026-09-15：训练优先的独立前端重设计，复用现有 React、Ant Design、ECharts 和单机 API。

## 页面结构

- 首页：真实资产数量、最近训练曲线、任务入口、服务器资源。
- 训练实验：新建实验 / 实验记录 / 数据缓存 / 运行资源。
- 模型验证：单图预测 / 独立评测；模型库折叠展示。
- 结果分析：已完成训练或独立评测对比、导出。
- 研究扩展：隐私保护、后门攻防，只预留路由和布局，无执行接口。
- `/demo`：原地图演示，独立全页加载，样式与真实任务控制隔离。

现有 `?view=`、任务 ID 和旧路径继续有效。训练子页切换保留未提交配置；修改参数会使预检失效。提交过程中锁定参数。高级参数、日志、配置版本及评测口径可展开查看，重要来源限制仍然直接提示。

## 验证与发布

- 41 项前端测试通过，包含导航、离线状态、参数提交、预检绑定与失效、生成模式、参数锁定、单图预测与旧地图隔离。
- TypeScript 与 Vite 构建通过；现有图表依赖仍触发大体积 chunk 提示。
- 浏览器检查真实后端数据、手机 390px 布局、菜单关闭、页面滚动复位及表单溢出。
- 构建仅更新 4090 独立工作树的 `frontend/dist`，保留旧散列资源和入口备份，不重启后端，不迁移模型或修改数据集。
- 正式任务提交从同源服务地址验收；不为开发代理关闭后端的 Origin 校验。

后续隐私与后门能力应接入独立配置、任务类型和真实结果协议，再将 `extensions.tsx` 中的 planned 状态升级；不能借用准确率 API 伪装已实现。
