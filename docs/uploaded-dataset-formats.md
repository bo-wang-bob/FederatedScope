# 上传图片与标签

训练集、测试文件夹、单张图片使用同一上传解码流程。

支持扩展名：jpg、jpeg、jpe、jfif、png、apng、webp、bmp、dib、tif、tiff、gif、avif、heic、heif、jp2、j2k、ppm、pgm、pbm、pnm、tga，大小写均可。RAW、SVG、PSD、视频不在本接口支持范围内，应先转换为 PNG/JPG；前端会报错，不静默漏掉这些文件。

新上传图片经过真实解码、EXIF 方向校正、第一帧/第一页选择及 RGB 转换（透明部分为白底），作为无元数据的静态 PNG 供预览、特征提取与推理使用。原文件独立保存在对应上传目录的 originals/，清单记录原路径、原文件与规范化文件哈希、实际格式、尺寸和转换版本。已有上传与缓存不做回写转换。

单张原文件和转换后 PNG 均限 25 MiB，最多 4000 万像素；每数据集最多 50000 张，原文件与转换文件合计最多 20 GiB。解码失败、损坏、超限均拒绝登记。

部署需要 Pillow 11.3.0 和 pillow-heif 0.22.0，已包含在 deploy/requirements-runtime.lock；没有更换 PyTorch、CUDA 或 GPU 默认配置。

## 标签规则

- 当前是整图分类，训练类别来自直接子文件夹名称，不解析图片文件名或检测框标注。
- 例如 `训练集/F-16/001.jpg` 的标签为 `F-16`，`训练集/C-130/002.png` 的标签为 `C-130`。训练至少两类、每类至少三张；分类不确定的图片先留在数据集之外，待人工确认后加入。
- 纯图片测试文件夹无需标注，可以输出预测类别和分类分数；需要准确率时，应提供经人工确认、与所选模型类别一致的类别子文件夹。
- 没有人工标签时，可以先用已有模型进行候选类别预标注，再由人工复核并整理成类别文件夹。预测结果/置信度不是正确性保证，不能拿预测标签作为评测真值；当前未实现自动标注管理界面。
- 新测试图片应独立于训练来源，正式比较算法前应固定人工审核过的测试集。
