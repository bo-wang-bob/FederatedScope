# 全域智汇前端

跨军事域联邦学习单机模拟展示平台。前端通过固定种子模拟中央服务器、域子服务器和逻辑节点的三级态势，不要求后端实现真实分层聚合。

## 本地运行

```bash
npm install
npm run dev
```

访问 `http://127.0.0.1:5173/`。

## 构建与测试

```bash
npm run build
npm test
npm run test:e2e
```

当前实现默认使用演示数据，可完整浏览全屏综合态势、场景与异构分析、实验配置、运行监控、隐私攻击效果、攻防对照和实验报告页面。

综合态势与运行监控使用 `resource/4o28b0625501ad13015501ad2bfc0135.jpg` 作为地图底图，在前端叠加数字孪生域、战术符号域、装备数据库域和实景侦察域。每个域包含一个模拟域子服务器和 15 个逻辑客户端，地图中心部署模拟中央主服务器；所有地理区域与部署位置均为展示用途。

场景与异构分析页将域间特征偏移保持为只读，只允许通过全局狄利克雷参数 `alpha` 调节域内分布，并逐域展示全部客户端的样本数量、类别计数和类别比例。

默认使用 `frontend_simulation` 数据适配器。后续联调轻量后端时设置：

```bash
VITE_DATA_SOURCE=backend VITE_API_BASE_URL=http://127.0.0.1:8000 npm run dev
```

训练事件适配器支持事件序号去重、SSE 重连和快照恢复；没有后端时继续使用同一数据契约驱动可复现的单机演示流程。
