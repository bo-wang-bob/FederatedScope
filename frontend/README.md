# 全域智汇前端

跨军事域联邦学习单机模拟展示平台。前端通过固定种子模拟中央服务器、域子服务器和逻辑节点的三级态势，不要求后端实现真实分层聚合。

## 本地运行

```bash
npm install
npm run dev
```

访问 `http://127.0.0.1:5173/`。

## 构建与测试

```bash
npm run build
npm test
```

当前实现默认使用演示数据，可完整浏览综合态势、场景编排、异构分析、实验配置、运行监控、隐私攻击效果、攻防对照和实验报告页面。

综合态势与运行监控使用 `resource/4o28b0625501ad13015501ad2bfc0135.jpg` 作为地图底图，在前端叠加西北沙漠区、北部山地区、中部城镇区和东部沿海区。每个区域包含一个模拟域子服务器和多个逻辑节点，地图中心部署模拟中央主服务器；所有地理区域与部署位置均为展示用途。
